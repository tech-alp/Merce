# Merce Foundation Fonts

The Foundation module bundles Material Symbols Rounded for the MaterialIcon
and AppIcon primitives.

The font was sourced from DankMaterialShell's bundled material-design-icons
assets:

- https://github.com/AvengeMedia/DankMaterialShell/tree/master/quickshell/assets/fonts/material-design-icons
- https://github.com/AvengeMedia/DankMaterialShell/tree/master/quickshell/assets/fonts/material-design-icons/variablefont

The Material Symbols / Material Icons font assets are Apache-2.0 licensed.
The complete license is retained in `MaterialSymbolsRounded/LICENSE`.

Theme-specific text fonts are managed separately by the design-token pipeline
under `tools/design-tokens/tokens` and `generated/themes/fonts`.
