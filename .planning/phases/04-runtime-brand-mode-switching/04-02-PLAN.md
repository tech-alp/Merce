## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| C++ tests -> private fixture constructor | Tests may exercise alternate manifest indexes and must not turn test hooks into public QML API. |
| QML probe -> Theme singleton | Probe verifies public API behavior through the same route consumers use. |
| probe assertions -> binding correctness claim | One-shot reads can miss binding failures; the probe must bind before switching. |
| verification commands -> phase acceptance | Passing builds without running the switch probe would bypass the Phase 4 behavioral requirement. |
