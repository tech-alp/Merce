<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| :/merce/themes/index.json -> registry model | Generated JSON controls physical resource paths. |
| resource JSON -> typed runtime apply | Malformed manifests must be rejected before Theme mutation. |
| requested theme/variant strings -> registry lookup | Untrusted runtime inputs must not become resource paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Tampering | MerceThemeRegistry path resolution | mitigate | Reject absolute paths, ../, slash separators, and arbitrary :/... values; resolve only index-listed relative filenames. |
| T-03-04-02 | Tampering | MerceThemeManifestLoader JSON parsing | mitigate | Parse with QJsonParseError, require object documents, schemaVersion 1, expected identity, and supported-section completeness. |
| T-03-04-03 | Spoofing | requested theme/variant | mitigate | Resolve only registered theme/variant entries from the normalized index; unknown inputs return structured errors. |
| T-03-04-04 | Repudiation | fallback behavior | mitigate | Log requested-load failures, usedFallback state, and default-load failure errors through a dedicated logging category. |
| T-03-04-05 | Denial of Service | broken default manifest | mitigate | Return ok=false when registry default fails instead of applying incomplete theme data. |
| T-03-04-06 | Supply Chain | runtime dependency confusion | accept | Loader uses Qt Core JSON/resource/logging APIs only; no new runtime dependency or package-manager install. |
</threat_model>
