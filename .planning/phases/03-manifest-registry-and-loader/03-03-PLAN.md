<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source-tree generated artifacts -> Qt resources | CMake packages committed generated JSON into MerceCore. |
| generated index -> resource aliases | Resource aliasing must keep paths under :/merce/themes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering | resource aliasing | mitigate | Use qt_add_resources with BASE generated/themes and PREFIX /merce/themes so aliases cannot drift into generated/themes/... paths. |
| T-03-03-02 | Denial of Service | missing generated artifacts | mitigate | Configure-time fatal errors name missing files listed by generated/themes/index.json. |
| T-03-03-03 | Elevation of Privilege | runtime path indirection | mitigate | CMake packages only built-in files; loader path safety remains in Plan 04 and must reject arbitrary :/... values inside index per D-04. |
| T-03-03-04 | Supply Chain | token build dependency | accept | This plan does not run npm or install packages; it consumes committed generated files per D-25. |
</threat_model>
