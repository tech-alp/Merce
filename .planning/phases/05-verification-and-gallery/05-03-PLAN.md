No high-severity threat is expected in this plan because it writes fixed local image artifacts and documents optional local debug inspection only. File-write and qmlagent exposure risks are mitigated explicitly.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argument -> export path | User-provided output directory controls where image files are written. |
| ThemeGalleryExport -> filesystem | QML capture route writes PNG artifacts. |
| optional qmlagent TCP -> running playground | Debug inspection attaches to a locally launched QML debug service. |
| docs/source -> downstream users | Documentation commands may be reused by developers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | `--export-theme-gallery <output-dir>` | mitigate | Accept output directory only, derive fixed filenames internally, create only the requested directory, and verify non-empty files under `docs/assets/theme-gallery`. |
| T-05-03-02 | Information Disclosure | exported PNGs | accept | Images contain public design-system token/component visuals only; no credentials or user data are present. |
| T-05-03-03 | Denial of Service | offscreen export route | mitigate | Export exactly three states, log failures, and exit nonzero on failed theme switch or failed save. |
| T-05-03-04 | Information Disclosure | qmlagent TCP debug service | mitigate | Document qmlagent as optional, loopback-only, explicitly launched with a chosen port, and not part of CI gates. |
| T-05-03-05 | Spoofing | visual evidence docs | mitigate | Documentation links to generated local files and records the exact command that produced them. |
| T-05-03-06 | Elevation of Privilege | dependency/network surface | mitigate | Do not add Spix, network services, package installs, or new runtime dependencies. |
| T-05-SC | Tampering | package/dependency surface | mitigate | No npm, pip, cargo, Spix, or external package install is planned. |
</threat_model>
