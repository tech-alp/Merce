<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QML caller -> `Theme.setTheme` | Untrusted brand/mode strings enter the C++ runtime. |
| `MerceTheme` -> manifest registry/loader | Runtime API must not derive resource paths or bypass registry validation. |
| loader result -> QML-visible active state | Loader fallback may change the actual applied brand/mode. |
| stable object pointer -> mutable sub-values | QML bindings depend on sub-object value notify signals, not top-level pointer replacement. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Tampering | `MerceTheme::setTheme` input | mitigate | Pass brand/mode directly to `MerceThemeManifestLoader::load`; never construct manifest paths from QML strings. |
| T-04-01-02 | Tampering | active state mutation | mitigate | Treat switch as a transaction; on `!result.ok`, log and return `false` before mutating active state or values. |
| T-04-01-03 | Tampering | fallback active state | mitigate | Update active state from `MerceThemeLoadResult.theme` and `.variant`, not from requested brand/mode. |
| T-04-01-04 | Denial of Service | QML binding invalidation | mitigate | Keep sub-object pointers stable and use `CONSTANT`; rely on sub-object `changed` signals from `applyManifestSection(...)`. |
| T-04-01-05 | Elevation of Privilege | runtime style scope creep | mitigate | Do not add `QQuickStyle`, `Qt6::QuickControls2`, or `qtquickcontrols2.conf` changes; Phase 4 changes Merce semantic values only. |
| T-04-01-06 | Information Disclosure | public diagnostics | mitigate | Do not expose `lastError`, `usedFallback`, or manifest paths through QML. |
</threat_model>
